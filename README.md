# YouTube Monochrome Gradient

A minimalist YouTube userscript that transforms the interface with a black-and-white gradient background and transparent UI elements.

YouTube arayüzünü siyah-beyaz gradyan arka plan ve şeffaf arayüz öğeleriyle özelleştiren minimalist bir userscript.

---

## ✨ Features | Özellikler

- **Monochrome Gradient:** Black-and-white gradient page background.
- **Transparent UI:** Transparent backgrounds for descriptions, comments, video cards and navigation.
- **Minimalist Design:** Clean and distraction-free appearance.
- **Lightweight:** Pure JavaScript and CSS. No external dependencies.
- **Compatible:** Designed for Tampermonkey and Violentmonkey.

### Türkçe

- **Siyah-Beyaz Gradyan:** Sayfa arka planında siyah-beyaz gradyan.
- **Şeffaf Arayüz:** Açıklamalar, yorumlar, video kartları ve menülerde şeffaf arka plan.
- **Minimalist Tasarım:** Sade ve dikkat dağıtmayan görünüm.
- **Hafif:** Saf JavaScript ve CSS. Harici bağımlılık gerektirmez.
- **Uyumluluk:** Tampermonkey ve Violentmonkey için tasarlanmıştır.

---

## 📦 Installation | Kurulum

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Download `youtube-monochrome-gradient.user.js` from this repository.
3. Open the downloaded file in your userscript manager.
4. Click **Install**.
5. Refresh YouTube.

### Türkçe Kurulum

1. [Tampermonkey](https://www.tampermonkey.net/) veya [Violentmonkey](https://violentmonkey.github.io/) eklentisini kurun.
2. Bu depodan `youtube-monochrome-gradient.user.js` dosyasını indirin.
3. İndirdiğiniz dosyayı userscript yöneticinizde açın.
4. **Yükle** düğmesine basın.
5. YouTube sayfasını yenileyin.
